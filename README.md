# 全方位すごろく (Zenhoui Sugoroku Online)

サイコロの目の数だけ好きな方向へ進み、通った道を塗って囲む陣取りすごろく。
友人と通話しながらブラウザで遊ぶ、2〜8人のチーム戦／個人戦(試作版)。
Next.js (App Router) + Socket.io によるリアルタイム対戦。ザクロの継承と同じ構成です。

## ローカル開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。カスタムサーバー(`server.ts`)が
Next.jsとSocket.ioを同一プロセス・同一ポートで提供します(`next dev`単体では動きません)。

### 1人でテストする

トップ画面の部屋コード欄に **`ZZZZZ`** を入れて参加する(または `/room/ZZZZZ` を開く)と、
自分専用のテスト部屋が新しく作られ、ボット3体が入った状態(2対2)になります。
ボットはサーバー上で自動的に手番をこなします(`lib/bot.ts`)。ロビーではホストがボットの追加・削除・チーム移動をできます。
人間が全員切断するとボットも止まります。

外部からボットを参加させるスクリプトもあります(通常の部屋でも使えます)。

```bash
npx tsx scripts/bots.ts <部屋コード> 3
```

ルール処理だけを大量のランダム対戦で検証するには:

```bash
npx tsx scripts/simulate.ts 300
```

## ゲームルール実装メモ

- モード: チーム戦(青 vs 赤、2〜8人)/ 個人戦(2〜4人、赤・青・緑・紫)。ロビーでホストが切替、チーム戦は各自がチームを選ぶ
- 盤面: 自動生成(`lib/mapGen.ts`)。山は山脈と単独峰、川は山のそばから湧いて盤面の端(または別の川)まで1マス幅で途切れずに流れる、森はまとまった林、氷河は盤面の外周付近だけ。サイズは人数で自動(〜4人30×30、〜6人35×35、それ以上41×41)。ロビーで変更可。盤面の外周はティール色の枠線で表示。大きい盤面はスクロールし、自分の手番では自分のコマへ自動で寄る
  - 開始地点: チーム戦は各プレイヤーが別々の場所(盤面全体に散らばる)、個人戦は各色が隅寄り(盤面の20%内側)。それぞれ周囲3×3が最初の陣地
- 手番: チーム戦は青1→赤1→青2→赤2…と交互、個人戦は参加順。全員1回ずつで1セット → 得点計算
- サイコロ: 毎ターン2個振り、合計が移動力(`DICE_COUNT`)
- 移動: 上下左右に1マスずつ(クリックまたは矢印キー/WASD)。何度曲がっても、来た道を戻ってもよい。出た目はぴったり使い切る
  - 他のコマのマスは通過可(色も変わる)が止まれない。止まれるマスがなくなる手は打てない(`canFinish`)
  - どうしても使い切れないときだけ「これ以上進めないので終了」できる
- 塗り: 通過マスが自分の色に(上書き可)。自分の色で囲った、盤面の外とつながらない領域は自分の色に(`captureEnclosed`)
- 霧: コマの周囲2マス(5×5)が見える。晴れたマスは見えたまま、同じ色(味方)で共有。フラッグは誰かが見つけた時点で全員に公開
- 得点: マス数が単独最多の陣営に1点 + その陣営が支配(自分の色)しているフラッグ1本につき+1点。同数は0点
- 勝利: 目標点(既定15)到達、または塗れるマスの規定割合(既定75%)以上を1色で塗る(各手番の終わりに判定)
- 地形・設備(`lib/content.ts`)
  - 山: 通行不可 / 森: 進入コスト2 / 川: 通行不可。隣の川をタップすると橋を架けられる(誰でも通れる)。
    手番の最初に架けるとその手番は終了、移動中に架けるとそこで移動終了・次のターンは1回休み(`resting`)
  - 氷河: 通れるがずっと白(囲っても塗れない)
  - 遺跡: 踏むとサイコロ、次のターンに効果。1回で崩れて消える
  - 宝箱: 踏むとアイテム1個(所持上限3。満杯なら開けられず残る)
  - 洞窟: 移動をぴったりそこで終えるか、途中で「洞窟に入る」で入る。次のターンから毎ターン振った目を合計し、
    脱出値(既定20。サイコロ2個の合計を足していく)以上で2個から1個選んで脱出、超えた分だけ進める。中にいる間は動けず、そのマスは塗り替えられない
- アイテム: 手番の最初(サイコロの前)に使う。ダッシュ/ローラー/爆弾/偵察/ワープ/防壁/妨害/橋キット
- 部屋の状態はサーバーのメモリ内で管理(`lib/rooms.ts`)。プロセス再起動で消えます

## クラウドデプロイ

ザクロの継承と同じく、付属の `Dockerfile` で常駐プロセスを実行できるホスティング(Railway, Render, Fly.io など)にデプロイできます。

```bash
docker build -t zenhoui-online .
docker run -p 3000:3000 zenhoui-online
```
